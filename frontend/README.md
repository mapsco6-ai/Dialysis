# نبض — واجهة نظام إدارة مركز الديلزة

واجهة أمامية (React + TypeScript + Vite + Tailwind) تتصل بالباك اند في جذر هذا المستودع.

## التشغيل محليًا

```bash
npm install
npm run dev
```

الخادم الافتراضي هو `http://localhost:5173`، ويوجّه أي طلب لمسار `/api` تلقائيًا إلى الباك اند على `http://127.0.0.1:8010` (انظر `vite.config.ts`). شغّل الباك اند أولًا:

```bash
cd .. && python manage.py runserver 8010
```

## البنية

- `src/api/` — عميل Axios (JWT + تجديد تلقائي للتوكن) وخطافات React Query لكل نقطة API
- `src/auth/` — سياق المصادقة، الأدوار السبعة، حارس المسارات المحمية
- `src/components/layout/` — الهيكل العام (شريط جانبي + شريط علوي)، بما فيها قائمة التنقل المفلترة حسب الدور
- `src/components/ui/` — مكونات مشتركة (بطاقة، بطاقة إحصائية، شارة حالة)
- `src/pages/` — الشاشات الفعلية، مبوّبة حسب القسم

الواجهة عربية بالكامل (RTL) لأن المستخدمين الفعليين طاقم عراقي.
